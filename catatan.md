# OPERASI KOMPARASI
1. ><, >=, <=, ==, != : mereka ini dapat bekerja pada syntax literal
2. contoh = 
   a == 4 (a ada nilainya dan memakan memori (yg ditaro di komputer), sedangkan 4 adalah literal karena gada variabelnya jadi lgsg nilai ajah, dan tidak memakan memori)
3. 'is' = membandingkan memory/objek
   contoh : a = 4, b = 4, a is b (ini benar)
   kalo misalkan 'a is 4' (tidak benar)
